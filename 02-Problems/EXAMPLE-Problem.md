# EXAMPLE: 我想转型独立创业但还没找到方向

> 这是一个**示范** Problem 文件。${USER_NAME} 完成 onboarding 后，自己写真实的 Problem 时可以参考此格式。
> 写完真实 Problem 后，可以删除此文件。

## 这是什么问题（核心叙述）

我做着一份还行的工作，但越来越觉得不是我想要的。我有一些技能和热情，想看能不能靠自己变现，过上更自由的生活。但具体方向、产品形态、要不要先离职，都不清楚。

## 为什么这是 Problem 而不是 Project

- **不是"明确要做什么"**：方向都没定，谈不上 project
- **持续性**：这个状态可能持续几个月到一年
- **影响日常工作**：每天都在这个状态里挣扎

## ≤3 原则

战略问题硬性 ≤ 3。如果你想到的"问题"超过 3 个，说明还没收敛到真正的赌注。
重新审视：哪 1-3 个问题如果解决了，其他都自动顺了？

## 写法对比

❌ **反例**："我没有现金流"
- 太大、太焦虑、不可行动

✅ **正例**："我想转型独立创业但还没找到方向"
- 具体：知道要做的是"找方向"
- 可对应日常工作：每天观察/学习/试小项目都在解这个问题
