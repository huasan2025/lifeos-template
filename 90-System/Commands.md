# Commands

这里记录 AI 助理可用的命令。
这些命令不是为了炫技，而是为了在高频决策场景中，稳定调用系统级上下文。

## `/today`

### 作用
基于我的身份、原则、当前状态、当前问题和当前项目，判断今天最值得推进的 1-3 件事。

### 读取内容
- [[Who I Am]]
- [[Soul]]
- [[Current State]]
- [[Today]]
- 从 `Today` 中动态识别当前活跃的 Problem 和 Project
- 如果 `Today` 缺失，再从 `Current State` 中回退识别
- 然后读取对应的 Problem note 和 Project note

### 输出内容
- 今日判断
- 今天只做这 1-3 件事
- 为什么是这几件
- 今天不要做
- 最小保底动作

### 使用原则
- 优先真实问题，而不是自我感动
- 优先资产积累，而不是临时忙碌
- 优先接近现金流的动作
- 如果我在逃避关键问题或被新灵感带偏，要直接指出
- 最终决策以我的意志为准

## 后续可增加的命令
- `/focus`
- `/should-i-do`

只有在 `/today` 已经稳定有用之后，才继续扩展。
