# EXAMPLE: 一次性问题的解决经验

> **type: howto** 的 Library 文件，记录解决过一次的问题。

## 何时写这种文件

- 项目过程中遇到一个技术 / 操作问题
- 用 AI 解决了，过程值得记下来
- 未来类似问题再出现，能直接读这个不用重新摸索
- 也可以作为教学素材分享

## 模板

把"问题描述 + 解决步骤 + 学到的"写下来。

格式自由，但建议有：
- **问题**（一句话讲清楚是什么）
- **解决步骤**（按时间顺序，可贴代码 / 命令 / 截图）
- **关键判断**（哪一步是核心的"啊哈"时刻）
- **延伸适用场景**（这个解法还适用于哪类问题）

## 子分类（可选用 tags）

- 工具配置：环境搭建、软件 setup
- 代码踩坑：bug 解决记录
- 工作流程：流程优化记录
