# EXAMPLE: 外部内容的消化产出

> **type: decode** 的 Library 文件，记录读 / 听 / 看完外部内容（文章、播客、视频、书）后的消化结果。

## 何时写这种文件

- 看完一篇深度文章 / 听完一期播客 / 读完一本书
- 觉得有些观点值得保留，未来可能引用
- 用自己的话写一遍，不只是 highlights

## 模板

- **来源**：作者 + 链接 + 标题
- **核心论点**（3-5 条，用自己的话说）
- **我同意的部分**（为什么）
- **我质疑的部分**（为什么）
- **可应用到我的场景**（哪些观点能落到我的 Project / Problem）

## 与 type: insight 的区别

- decode = 别人的观点，我整理 + 评价
- insight = 我自己的洞见，从经验提炼
