# EXAMPLE: 独立洞见 / 原则卡

> **type: insight** 的 Library 文件，记录从经验提炼出的可复用洞见。

## 何时写这种文件

- 从某次踩坑 / 成功 / 观察中提炼出一个**普适规则**
- 这个规则未来会反复用
- 不属于某个具体项目（如果属于，写在项目里就行）

## 模板

- **触发事件**（什么事让你想到这条 insight）
- **洞见叙述**（一句话提炼，加 1-2 段展开）
- **应用条件**（什么场景下适用 / 不适用）
- **反例**（如果有，列一个反向例子）

## 命名建议

文件名直接用 insight 内容（如 `深度思考是行动的副产品.md`），方便回看时一眼识别。
