对 vault 做一次结构自检，把 CLAUDE.md 里那些"写了但没强制执行"的硬约束自动扫一遍。

## 定位

`/lint` 只做**结构自检**，不做经验蒸馏（那是 `91-Assistant/Evolution Rules.md` 的事，别混进来——一个命令只干一件事）。

把 vault 维护想成三类动作：**写入**（`/save` `/capture`）+ **读取/判断**（`/go`）+ **自检**（本命令）。前两类把内容沉淀进系统、把上下文读出来，`/lint` 负责确认这套文件系统没有内部腐化。

## 只报告，不自动改

发现问题列清单给${USER_NAME}，由他决定怎么修。**不要擅自移动文件、改 frontmatter、删笔记**——那会触发 wikilink 连锁断裂，正是 `/lint` 要防的事。

## 扫描时间戳（每次全量扫描必做）

1. **开扫前**：读 `90-System/lint-log.md` 最后一行，报告头部显示「上次扫描：{{上次时间}}」。文件为空则提示"首次扫描"。
2. **取真实时间**：用 Bash `date "+%Y-%m-%d %H:%M"`，不要凭空写日期。
3. **扫完后**：往 `90-System/lint-log.md` **追加一行**（append-only，最新在底部）：
   ```
   - {{YYYY-MM-DD HH:MM}} — 扫描 N 篇 · 死链 X · 越界 Y · 孤儿 Z（全清则写"结构干净"）
   ```
   这份 log 同时充当系统结构演化的 append-only 日志。

## 检查清单（6 项）

逐项扫描 vault 根目录下所有 `.md`。**扫描范围必须排除**：`99-Archive/`、`.obsidian/`、`.git/`、`.claude/`、`node_modules/`（第三方包 README 满是 `[[1, 2]]` 误报）、以及任何存放规划/spec 草稿的目录（里面常有 `[[文章标题]]` `[[EXAMPLE]]` 模板占位符）。

1. **死 wikilink**：所有 `[[X]]` / `[[X|别名]]` / `[[X#标题]]`，目标 note 在 vault 里不存在 → 报「源文件 → 断链目标」。
   匹配前先 **strip 掉代码块/行内代码**，并滤掉以下**非死链**：
   - **外部文章标题**：指向外站文章的长标题（含书名号《》、明显是文章标题的），是来源指针不是 vault note，归到 ⚪ 提示，不判死
   - **代码/占位符误报**：含 `" , $ * ^ { } /` 或多词英文、`.md/.png/.canvas` 结尾、`xxx`/`EXAMPLE` 占位符
2. **命令死引用**：`.claude/commands/*.md` 与 `90-System/Commands.md` 里写到的 vault 路径（`90-System/...` `00-Dashboard/...` 等）文件是否仍存在 → 报。结构重构后命令没同步是最常见的腐化源
3. **Problem 超限**：`02-Problems/` 下 `type: problem` 且 `status: active` 的笔记 > 3 → 报（硬上限 ≤3）
4. **Project 未锚定**：`type: project` 的笔记 frontmatter 缺 `problem:` 字段，或 `problem:` 指向不存在的 Problem → 报（每个 Project 必须锚定一个 Problem）
5. **孤儿笔记**：没有任何其他笔记链入的 note（各目录入口笔记、`00-Dashboard/` 索引类、`PROGRESS.md` 等枢纽文件除外）→ 报为「可能失联」，仅提示不判死
6. **缺入口笔记**：`03-Projects/<name>/` 目录被别处按 `[[<name>]]` 双链，但目录里没有 `<name>.md` 入口笔记（「每个 Project 子目录用 `<目录名>.md` 做入口」约定）→ 报

## 输出格式

```markdown
## /lint 自检报告（{{本次扫描时间 YYYY-MM-DD HH:MM}}）
> 上次扫描：{{lint-log 最后一行的时间，或"首次"}}

### 🔴 死引用（必修）
- 命令死引用：{{文件}} 引用了不存在的 {{路径}}
- 死 wikilink：{{源笔记}} → [[{{断链目标}}]]

### 🟡 约束越界
- Problem 超限：当前 {{n}} 个 active，超过 ≤3
- Project 未锚定：{{项目}} 缺 problem: 字段
- 缺入口笔记：{{项目}} 被双链但无 {{name}}.md

### ⚪ 提示（自行判断）
- 孤儿笔记：{{笔记}}（无入链，确认是否还需要）

### 小结
扫了 {{n}} 个笔记，{{发现/未发现}} 结构问题。
```

全部通过时直接说「结构干净，无死引用 / 无越界 / 无孤儿」，不要硬凑问题。

## 与 /save 的分工

`/save` 折叠了轻量版（仅 #1 #2，只查本次会话动过的笔记，图快）。独立 `/lint` 跑全量 6 项、扫全库。日常 checkpoint 靠 save 兜底，结构大改后或定期手动跑一次 `/lint` 做深度体检。
