# EXAMPLE: 跨项目 / 跨案例的分析

> **type: analysis** 的 Library 文件，对一个主题、一类产品、一个案例做结构化拆解。

## 何时写这种文件

- 想拆解一个产品（如"分析 X 产品的商业化路径"）
- 想对比一组案例（如"对比 5 个出海工具的引流策略"）
- 写着写着 insight / decode 越来越长，需要更结构化的篇幅

## 模板

- **主题**（一句话）
- **拆解角度**（用什么维度切）
- **核心发现**（每个维度的关键观察）
- **可借鉴部分**（落到 my Project / Problem）
- **延伸阅读**（如有引用其他文章 / 数据）

## 与其他 type 的区别

- howto = 解决一个具体问题
- decode = 消化一份外部内容
- insight = 提炼一个独立观点
- **analysis = 系统拆解一个主题（综合性最强）**
